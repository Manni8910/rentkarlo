# Rent Karlo

Vercel-ready Next.js rental marketplace MVP.

## Start locally
```bash
npm install
npm run dev
```

## Deploy
Push this folder to GitHub, import the repository into Vercel, and use the default Next.js settings.

## Connect rentkarlo.co.in
Open the Vercel project, go to Settings → Domains, add `rentkarlo.co.in`, and apply the exact DNS records Vercel displays at your domain registrar.
